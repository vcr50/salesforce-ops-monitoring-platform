# SentinelFlow + Zentom AI v1.2.0 — Premium UI/UX Redesign Concept

This document presents the visual redesign blueprint for SentinelFlow + Zentom AI v1.2.0. The design fuses Samsung One UI interface principles, clean Salesforce console ergonomics, and modern AI operations platform polish to establish a high-end, AppExchange-ready enterprise SaaS product.

---

## 1. Design Mindset: Samsung One UI & Night Mode

Following the Samsung One UI design philosophy, the user interface focuses on clarity, calm layout structure, and comfortable physical interaction bounds.

### Night Mode Look (Dark Mode)
*   **Background Surfaces**: Soft charcoal and graphite hues (e.g. `#1b1e22` and `#24282e`) to minimize eye strain and eliminate harsh pitch-black contrast.
*   **Elevations**: Soft-lit, layered surfaces (`#2d323a`) representing active interactive levels.
*   **Borders & Highlights**: Subtle, thin borders (`#3b424d`) with soft ambient glows to separate components cleanly.
*   **Contrast**: Muted, accessible text contrast using soft whites (`#e3e8f0`) and subtle gray body text (`#a0aec0`).

### Day Mode Look (Light Mode)
*   **Background Surfaces**: Crisp, soft white and warm off-white tones (`#f4f6fa` and `#ffffff`).
*   **Accent Color**: High-contrast modern blue (`#0176d3`) acting as the primary action accent.
*   **Card Separation**: Soft, multi-layered card components separated by subtle shadows (`0 4px 12px rgba(0,0,0,0.03)`).

---

## 2. Redesigned Layout & Unified Navigation

The application uses a stable left-aligned sidebar with clear vertical grid grids and a responsive top utility bar.

*   **Left Navigation**: Expanded menu spacing with a 12px gutter. Unified, modern SVG icons for all primary modules.
*   **Functional-Only Pages**: Incomplete tabs (Cases, Policies, Runbooks) are hidden from default view behind default-off toggles to prevent "Coming Soon" placeholders from cluttering the production environment.
*   **Stable Top Bar**: Exposes the system health state, local clock, quick global search (accessed via `/` key), and user org profiles.

## 4. Visual System & Typography Specs

### Typography Hierarchy
*   **Headers & Titles**: Confident, semi-bold titles using system-level sans-serif fonts (e.g. `Segoe UI`, `System-UI`).
*   **Content Labels**: Small, uppercase, high-contrast labels (`font-size: 0.6875rem`, `letter-spacing: 0.03em`).
*   **Body & Descriptions**: Accessible height spacing (`line-height: 1.45`).

### Status Color Palette
Premium, muted status chips replace generic primaries:
*   `Critical`: Crimson background with a soft red border and text.
*   `High` / `Warning`: Amber/yellow text overlays.
*   `Medium`: Gold and soft yellow tones.
*   `Low` / `Healthy`: Soft forest green text and light mint backgrounds.
*   `Resolved` / `Action Created`: Pastel teal or blue badges.

---

## 5. UI/UX Remediation Summary

1.  **AI Assistant Air-Gap**: The floating copilot mascot and its speech bubbles are completely removed from the default layouts, keeping the chat experience confined to the Zentom AI Console tab with safe greeting copy.
2.  **Settings Page Cleanup**: Obsolete dark overlay boxes are replaced with clean light/dark mode responsive forms. Spacing is extended, and input fields use distinctive active border states.
3.  **No Placeholders**: Clickable paths fall back safely to active incident pages instead of showing inactive placeholder templates.
