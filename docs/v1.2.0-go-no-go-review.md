## 7. Known Limitations
* **Apex CLI Test Boundaries**: Unit test boundaries (`Test.startTest()` / `Test.stopTest()`) are not supported in anonymous CLI runs and must be run as native Apex tests.
* **Async Webhook Fallbacks**: In case of Slack or Teams webhook delivery failures, async email notifications are scheduled fallback-style to prevent locks on parent incident tables.

---

## 8. Open Risks
* **Tuning UI Deferral**: Calibration sliders are deferred to v1.3.0. Currently, parameter weights are safely managed via custom metadata settings. No release blocker risks exist.
