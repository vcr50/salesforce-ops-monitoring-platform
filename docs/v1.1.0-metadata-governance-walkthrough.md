# Metadata-Driven Governance Walkthrough (Milestone 46C)

## 1. Overview
In Milestone 46C, we successfully migrated hardcoded governance thresholds (the `$50,000` autonomous risk threshold and the `4-hour` SLA escalation duration) to Salesforce Custom Metadata using the `System_Setting__mdt` Custom Metadata Type. This allows administrators to customize these parameters dynamically without requiring code modifications or deployments.

## 2. Changes Made

### Custom Metadata Records

- **[NEW]** `System_Setting.Escalation_Threshold_Hours.md-meta.xml`:

- **[NEW]** `System_Setting.Revenue_Risk_Threshold.md-meta.xml`:
  - Sets the default autonomous risk/ARR threshold to `$50,000.00`.

## 4. Administration Instructions
To modify these thresholds in Salesforce:
1. Navigate to **Setup** → **Custom Code** → **Custom Metadata Types**.
2. Click **Manage Records** next to **System Setting**.
3. Edit the following records as required:
   - **Revenue Risk Threshold**: Set the new value in the `Value` field (e.g., `75000` to allow autonomous healing up to $75k).
   - **Escalation Threshold Hours**: Set the new SLA limit in hours (e.g., `2` or `8`).
4. Click **Save**. The application will instantly reflect these updates on the next transaction or dashboard refresh.
