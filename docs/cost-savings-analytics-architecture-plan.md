## 1. Purpose

The purpose of this architecture plan is to design the **Cost Savings Analytics Dashboard Widgets** for the SentinelFlow Incident Command Center. These widgets will demonstrate the concrete financial and operational value generated by SentinelFlow's autonomous operations to enterprise stakeholders.

The metrics displayed will include:
1.  **Successful Recoveries**: Count of incidents autonomously mitigated.
2.  **Hours Saved**: Productive engineering time reclaimed by automation.
3.  **Cases Avoided**: Salesforce Support Cases that were prevented because the system self-healed.
4.  **Estimated Cost Savings**: Explanable dollar value of resources saved.
5.  **MTTR Improvement**: Comparison of automated resolution speed against baseline manual MTTR.

---

## 2. Configurable Assumptions (Custom Metadata)

To maintain absolute transparency and prevent fake financial claims, all calculations are based on configurable assumptions defined in `System_Setting__mdt` Custom Metadata.

| Setting Developer Name | Type | Default Value | Purpose |
|---|---|---|---|
| `Engineering_Hourly_Rate` | Decimal | `80.00` | Fully loaded cost per engineer hour (USD). |
| `Manual_Resolution_Hours` | Decimal | `2.00` | Average time a human engineer takes to resolve an incident manually. |
| `Baseline_MTTR_Minutes` | Decimal | `240.0` | Historic manual Mean Time to Resolution (4 hours). |
| `Cost_Per_Support_Case` | Decimal | `150.00` | Estimated overhead cost of a customer-submitted Support Case. |

## 3. Explainable Formulas & Logic

Every metric is backed by a clear, explainable formula that operators can inspect via UI tooltips.

### A. Successful Recoveries
*   **Definition**: Any incident that reached a closed/resolved state after automation was executed successfully.
*   **Formula**:
    ```
    Successful Recoveries = Count of Sentinel_Incident__c where
       Execution_Status__c = 'Executed'
    ```

### B. Hours Saved
*   **Definition**: Time saved by substituting manual engineering triage with automation.
*   **Formula**:
    ```
    Hours Saved = Successful Recoveries * Manual_Resolution_Hours
    ```

### C. Cases Avoided
*   **Definition**: Incidents that were resolved autonomously without requiring escalation to an external Salesforce Case.
*   **Formula**:
    ```
    Cases Avoided = Count of Sentinel_Incident__c where
       Execution_Status__c = 'Executed' AND Created_Case__c = null
    ```
    *(Note: If a runbook execution results in creating a case for administrative tracking, that incident is excluded from cases avoided).*

### D. Estimated Cost Savings
*   **Definition**: Financial savings calculated from reclaimed engineering time and avoided support ticket overhead.
*   **Formula**:
    ```
    Estimated Cost Savings = (Hours Saved * Engineering_Hourly_Rate) 
                            + (Cases Avoided * Cost_Per_Support_Case)
    ```

### E. MTTR Improvement
*   **Definition**: The percentage decrease in MTTR compared to the manual historic baseline.
*   **Formula**:
    1.  *Automated MTTR (Minutes)* = Average of `(Executed_At__c - CreatedDate)` in minutes for all `Execution_Status__c = 'Executed'` incidents.
    2.  *MTTR Improvement (%)* = `((Baseline_MTTR_Minutes - Automated_MTTR) / Baseline_MTTR_Minutes) * 100`
