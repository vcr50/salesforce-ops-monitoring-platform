# SentinelFlow + Zentom AI v1.2.0 - UI Placeholder Tab Remediation

This document records Milestone 71B-5, the remediation of visible placeholder tabs before AppExchange packaging.

---

## 1. Purpose

Milestone 71B-5 removes unfinished product modules from default customer-facing navigation so AppExchange reviewers and users only see functional pages.

Rule: clickable tab equals functional page.

---

## 2. Scope

Placeholder modules remediated:

- Cases
- Policies
- Runbooks

Implementation target:

- `force-app/main/default/lwc/sentinelFlowBetaAppShell`

---

## 3. AppExchange-Safe Decision

Selected option: Option A - Hide incomplete tabs from default navigation.

Rationale:

- Fastest safe path before packaging.
- Avoids exposing unfinished pages to reviewers.
- Keeps future modules documented without presenting them as active v1.2.0 product features.

---

## 4. Implementation Summary

Implemented default-off future module flags in `sentinelFlowBetaAppShell.js`:

```js
showCases = false
showPolicies = false
showRunbooks = false
```

Actual implementation uses a local `FUTURE_MODULE_FLAGS` config with all three values set to `false`.

Navigation updates:

- Cases sidebar tab is hidden by default.
- Policies sidebar tab is hidden by default.
- Runbooks sidebar tab is hidden by default.
- Disabled future routes are guarded in `navigate()`.
- If a disabled future route is requested, the user is routed to `incidents` instead of a placeholder page.

Internal link updates:

- Runbook links from dashboard incident context now route to functional incident detail flow instead of a placeholder Runbooks page.
- "Open Runbook" action was replaced with a functional incident-details CTA.

Placeholder cleanup:

- Removed "Coming Soon" page templates for Cases, Policies, and Runbooks.
- Removed unused placeholder styling for "Coming Soon" pages.

---

## 5. Acceptance Criteria

- [x] No visible "Coming Soon" tabs in default AppExchange-ready UI.
- [x] Clickable default tabs open functional pages only.
- [x] Future modules remain documented in roadmap/audit docs, not visible in app navigation.
- [x] No standard user-flow link routes to Cases, Policies, or Runbooks placeholders.
- [x] No "Coming Soon" strings remain in LWC source.
- [x] No `data-page="cases"`, `data-page="policies"`, or `data-page="runbooks"` routes remain in LWC source.
