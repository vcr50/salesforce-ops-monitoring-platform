## 8. Known Limitations
* **Apex CLI Limits**: Test context boundaries (`Test.startTest()` / `Test.stopTest()`) are not supported in anonymous CLI runs and must be run as native Apex tests.
* **Async Alerts Fallback**: Timeout and network delivery failures on external webhooks fall back to asynchronous email alerts to avoid locking parent records.
