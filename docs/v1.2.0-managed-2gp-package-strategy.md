## 8. Dev Hub / Package Commands

Documented verification commands:

```bash
sf org display --target-dev-hub <DEV_HUB_ALIAS>
sf package list --target-dev-hub <DEV_HUB_ALIAS>
```

If the installed Salesforce CLI does not support `sf org display --target-dev-hub`, use the supported equivalent:

```bash
sf org display --target-org <DEV_HUB_ALIAS>
```

Managed package creation command, after namespace confirmation:

```bash
sf package create \
  --name "SentinelFlow" \
  --package-type Managed \
  --path force-app \
  --target-dev-hub <DEV_HUB_ALIAS>
```

Package version creation command, only after managed package and aliases are confirmed:

```bash
sf package version create \
  --package "SentinelFlow" \
  --installation-key-bypass \
  --wait 60 \
  --target-dev-hub <DEV_HUB_ALIAS>
```

71C must not run the package version creation command until the success criteria in this document are met.
