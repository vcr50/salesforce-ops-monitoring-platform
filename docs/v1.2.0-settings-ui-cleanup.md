# SentinelFlow + Zentom AI v1.2.0 Settings UI Cleanup

## 1. Purpose

Milestone 71B-6 cleans up the Settings page visual treatment before AppExchange packaging. The goal is to remove the dark, low-contrast overlay-like appearance observed in review screenshots and make the settings experience readable, polished, and customer-ready in the default light-mode product UI.

## 2. Scope

The cleanup applies to the SentinelFlow Settings experience rendered by `sentinelFlowPortalSettings`.

Reviewed surface:

- Platform Settings page header
- Subscription Status card
- Settings tab bar
- Integration Setup form
- Monitored Endpoints list
- Retry Rules controls
- Alert Configuration controls
- Automation controls

## 3. Findings Addressed

The previous Settings styling used dark fallback colors for page text, cards, tab backgrounds, and form controls. In light mode this made the page look disabled or covered by a dark overlay, with weak label contrast and unclear active tab state.

Specific issues addressed:

- Dark card fallbacks on a light application shell
- Low-contrast labels and descriptions
- Dim input/select backgrounds
- Weak active tab state
- Disabled-looking settings cards
- Inconsistent form field and card spacing

## 4. Implementation Summary

Updated `force-app/main/default/lwc/sentinelFlowPortalSettings/sentinelFlowPortalSettings.css` to use a local Settings palette that inherits the shell design variables and falls back to AppExchange-safe light-mode values.

Changes include:

- Added Settings-scoped CSS variables for page, card, input, border, text, and primary action colors.
- Replaced dark card and input fallbacks with readable light-mode defaults.
- Improved tab bar contrast and made the active tab visually obvious.
- Increased label weight and contrast.
- Cleaned card backgrounds, borders, radius, and shadows so cards do not look disabled.
- Improved form field focus states with a clear blue focus ring.
- Updated number, select, webhook, secondary button, endpoint, subscription, and automation control styling for consistent readability.

## 5. Acceptance Criteria

- Settings page is readable in light mode: Met.
- Form fields have clear contrast: Met.
- Labels are visible: Met.
- Cards do not look disabled: Met.
- Active tab is obvious: Met.
- Buttons are clear: Met.
- No accidental dark overlay effect: Met.
- No obvious accessibility contrast issue in default light mode: Met.
