## 2. Component-Level Settings Page Alignments

The settings LWC stylesheet [`sentinelFlowPortalSettings.css`](file:///d:/TomCodeX%20Inc/SentinelFlow/force-app/main/default/lwc/sentinelFlowPortalSettings/sentinelFlowPortalSettings.css) has been cleaned of static day-mode fallbacks:

*   **Active Tab Background**: `.tab-btn.tab-active` uses `var(--settings-card-bg)` instead of static `#ffffff`, allowing the active tab button to adapt to the dark theme surface correctly.
*   **Select Form Options**: Input dropdown options (`select option`) utilize `var(--settings-card-bg)` and `var(--settings-text-strong)` to prevent white dropdown elements in dark mode.
*   **Shadow Variables**: Substituted hardcoded shadow overlays with `var(--shadow-light)` to prevent white box shadows in dark mode.
