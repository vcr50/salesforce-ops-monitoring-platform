## 4. Phase Breakdown

### Phase 0 — Foundation Reset ⚠️ BUILD FIRST

**Goal:** Prepare enterprise-grade platform architecture BEFORE scaling AI.

**Build:**
- RBAC + ABAC
- MFA + OAuth 2.0 + SSO
- Tenant isolation
- Secret vault
- Encryption at rest and in transit
- Immutable audit logs

> **WHY:** Trust becomes your moat.
